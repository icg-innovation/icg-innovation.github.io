# ICG RSE GitHub Pages

This repository hosts the official GitHub Pages website for ICG RSE. It serves as a central hub for showcasing our projects, initiatives, and resources.

You can visit the live site here: https://icg-rse.github.io

## About

This site is built using Jekyll and leverages the Cayman theme for its design.

## Local Development

To run this site locally:

1. Clone the repository: `git clone https://github.com/icg-rse/icg-rse.github.io.git`
2. Navigate to the directory: `cd icg-rse.github.io`
3. Install Jekyll and theme dependencies (if not already installed, assuming `Gemfile` exists): `bundle install`
4. Serve the site: `bundle exec jekyll serve`
5. Open your browser to `http://localhost:4000`
